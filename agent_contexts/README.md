# Generated agent contexts

The Markdown files in this directory are generated by `bun repomix` from the current source tree.
They are optional, scoped reference material for AI agents; the checked-out source is always the
source of truth.

## Choosing a context

- `base-*_context.md`: shared components, logic, infrastructure, tests, and configuration
- `main_context.md`: main application layer
- `open-api_context.md`: generated-client layer
- `showcases-*_context.md`: showcase pages, components, logic, tests, and configuration
- `showcases-animista-*_context.md`: one context per large Animista component

Use `rg` to locate the relevant source first, then open only the smallest matching context. Regenerate
the files after source changes with:

```sh
bun repomix
```
